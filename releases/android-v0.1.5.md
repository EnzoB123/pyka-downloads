# PYKA Android 0.1.5 preview

- Added chat @user suggestions, highlighted mentions and foreground mention notices.
- Added manual AFK entry and return to Lounge. Locked-phone calls stay connected.
- Added stream quality controls and received resolution/FPS, with tap-to-reveal controls.

Version code 6; ARM64; Android 8 or newer. This preview keeps the existing package
and test signing key so compatible earlier previews can upgrade in place. Physical
phone, Bluetooth and Android Auto audio qualification remains separate from build tests.
