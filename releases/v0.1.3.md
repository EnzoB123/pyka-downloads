# PYKA 0.1.3

- Refreshed voice interface with Lounge participants visible before joining and while browsing chat.
- Microphone settings, input monitoring, and noise suppression.
- Per-application audio sharing on supported Windows versions.
- Persistent sign-in with a 30-day session and compatibility for older clients.
- Fixes for interrupted joins, sign-out cleanup, and audio capture startup and shutdown.

Windows updates download in the background and install on normal exit. Versions without an updater need one manual installation.

Automated validation covers server and browser behavior, real WebRTC screen transport, Windows native capture, and installed desktop startup. Physical Windows audio quality, performance on different networks, and a two-version automatic-update rehearsal remain pending.

Windows 64-bit preview; unsigned builds can show a SmartScreen warning. An invitation code is required. Verify the installer and update files against the release's SHA256SUMS.txt.
