# PYKA 0.1.2

- Screen sharing defaults to 1080p at 30fps. Choose 480p, 720p, or 1080p and 15, 30, or 60fps in the screen picker.
- Delete your own messages in #general. Deletions synchronize with other updated clients.
- Image/GIF links, supported video links, and YouTube links show media previews.
- Windows updates download in the background and install on normal exit. Existing 0.1.1 users need to install this version manually once.

Validation includes automated server, browser, real local WebRTC, screen-share resolution and cleanup, and Windows native desktop-capture checks. Physical Windows system-audio/echo, motion performance on different networks, and a two-version automatic-update rehearsal remain pending.

Windows 64-bit preview; unsigned builds can show a SmartScreen warning. An invitation code is required. Verify the installer and update files against the release's SHA256SUMS.txt.
