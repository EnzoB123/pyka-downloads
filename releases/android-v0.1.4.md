PYKA Android 0.1.4 preview · Android 8+ · ARM64 phones.

- Cartola tab with the nine Carvoeiro Champions League teams, round/season scores, expandable player lineups and match schedules. Refreshes pause when you leave the screen or background the app.
- New shared PYKA launcher icon.
- Android Auto audio now waits for the system call to activate before microphone capture and playback begin. This fixes an audio-startup defect; a parked-car call is still needed to confirm echo behavior on your phone/car.
- Includes front/back camera switching, live audio-route display and synchronized avatars.

This APK keeps the existing Android preview/test signing key for compatibility with earlier PYKA test installations. It is a sideloaded preview, not a Play Store or production-signing migration. Package app.pyka.mobile, versionCode 5. Install over the earlier same-key preview to keep login and preferences; do not uninstall first.

SHA256SUMS lists the APK's checksum. Windows updates use a separate release and are unaffected by this Android prerelease.
