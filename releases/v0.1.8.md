# PYKA 0.1.8

- Added a silent AFK channel. Windows automatically moves you there after 20 minutes
  of computer inactivity; the setting is enabled by default and can be turned off.
- Added @user suggestions, highlighted mentions and notices when someone tags you.
- Stream controls now fade together, clearing the top of the video while watching.
- Added a Low quality viewing option and received stream resolution/FPS indicators.

This remains the unsigned Windows preview. Updates download in the background and
install when PYKA exits. Android has a separate preview release.
